安装

三步装好

1
打开 MedResearch Agent → 设置 → 插件
2
在输入框粘贴源地址（如 aipoch/medical-research-skills）→ 点 添加市场
3
在市场里找到插件 → 安装。装完在输入框打 ./ 就能调用
想自己写技能？技能就是一个带 frontmatter 的 Markdown 文件： skills/<slug>/SKILL.md，开头写 name 和 description，正文写方法论。 设置 → 规则/技能 里可以直接粘贴导入。
