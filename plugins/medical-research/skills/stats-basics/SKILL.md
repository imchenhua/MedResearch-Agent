# 常用统计分析

## 何时使用

- 比较两组或多组指标的差异
- 寻找影响结局的独立因素
- 分析生存时间 / 复发时间

## 方法选择（先看数据类型与分布）

| 场景 | 方法 |
|---|---|
| 两组连续变量，正态 | 独立样本 t 检验 |
| 两组连续变量，非正态 | Mann-Whitney U |
| 三组以上连续变量 | ANOVA / Kruskal-Wallis |
| 两组分类变量 | 卡方检验；期望频数 <5 用 Fisher 精确检验 |
| 配对前后比较 | 配对 t / Wilcoxon 符号秩 |
| 二分类结局 + 多因素 | Logistic 回归 |
| 生存时间 | Kaplan-Meier + log-rank；多因素用 Cox |

## 执行要求

1. **先做前提检验**：正态性（Shapiro-Wilk）、方差齐性（Levene），据此决定参数或非参数方法
2. 用 Python（`scipy` / `statsmodels` / `lifelines`）或 R 执行，**不要手算**
3. 报告格式：统计量 + 自由度 + **P 值 + 效应量 + 95% CI**
4. 多重比较必须做校正（Bonferroni / FDR），并说明用的是哪种

## 常见错误（要主动避免，并在用户要求这么做时提醒）

- 不看分布直接上 t 检验
- 只报 P 值，不报效应量和置信区间
- 把 P>0.05 说成「两组相同」（应表述为「未发现统计学差异」，并注意把握度）
- 对生存数据用 t 检验

## 输出

1. 方法选择理由（为什么用这个检验）
2. 前提检验结果
3. 主结果表
4. 一句话结论，**不超出数据能支持的范围**
