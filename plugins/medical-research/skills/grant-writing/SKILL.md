# 基金申请书撰写

## 何时使用

- 撰写国家自然科学基金（面上 / 青年）、省部级或院内课题申请书
- 修改现有申请书的某一节
- 以评审视角模拟挑毛病

## 核心结构（以国自然为例）

| 部分 | 要写什么 | 评审关注点 |
|---|---|---|
| 立项依据 | 领域现状 → 关键科学问题 → 本研究的切入点 | 科学问题是否清晰、是不是真问题 |
| 研究内容与目标 | 3–4 条具体内容，对应可考核目标 | 是否聚焦、3 年内能否做完 |
| 研究方案 | 技术路线、实验设计、统计方法、样本量 | 可行性、方法是否匹配问题 |
| 创新点 | 2–3 条（理论 / 方法 / 应用） | 是否真新，慎用「首次」 |
| 研究基础 | 前期数据、相关论文、团队与平台条件 | 有无预实验支撑 |
| 预期成果 | 论文、专利、人才培养 | 是否合理，不要虚高 |

## 写作要求

1. **科学问题要能用一句话说清** —— 说不清通常意味着还没想清
2. 技术路线配**流程图**，比大段文字有效得多
3. 样本量必须给出估算依据（α、把握度、预期效应量）
4. 创新点要能回答「凭什么你能做、别人为什么做不了」
5. **预实验数据是最有说服力的部分**，优先展示

## 常见硬伤（主动检查）

- 立项依据堆砌文献，始终没收敛到一个具体科学问题
- 研究内容铺得过大，明显超出资助周期
- 缺样本量估算或统计方法描述
- 创新点空泛（「填补空白」「国际领先」这类表述没有信息量）
- 研究基础与申请内容脱节

## 输出

按章节给出正文，并**附一份评审视角自评**：最可能被质疑的 3 个点 + 每个点的应对说明。
