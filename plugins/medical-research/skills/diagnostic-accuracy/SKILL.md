# 诊断准确性研究

## 何时使用

- 评估某个检查、生物标志物或影像的**诊断价值**
- 需要计算敏感度 / 特异度 / AUC
- 撰写或审阅按 STARD 报告的研究

## 核心指标

| 指标 | 含义 | 注意 |
|---|---|---|
| 敏感度 | 有病者被检出的比例 | 与特异度此消彼长 |
| 特异度 | 无病者被排除的比例 | 受阈值影响很大 |
| PPV / NPV | 阳性 / 阴性预测值 | **随患病率变化**，不能跨人群照搬 |
| 似然比 LR+ / LR- | 阳性 / 阴性似然比 | 相对稳定，跨人群更可靠 |
| AUC | ROC 曲线下面积 | 只反映区分度，不含校准度 |

## 关键要求

1. **先给四格表**：TP / FP / FN / TN —— 所有指标都应能从中推出
2. **阈值来源必须写明**：预设还是从数据里挑的（后者会高估性能）
3. 所有指标报告 **95% CI**，不能只给点估计
4. 主动检查三类偏倚：谱偏倚（病例是否过重）、金标准不完美、有无盲法
5. 多指标比较时用 DeLong 检验比较 ROC 曲线，不要只看 AUC 谁大

## 输出

1. 四格表
2. 各诊断指标 + 95% CI
3. ROC 曲线与 AUC
4. 偏倚风险提示（按 QUADAS-2 的四个维度）
