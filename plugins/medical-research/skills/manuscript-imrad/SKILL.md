# 论文写作与投稿自查

## 何时使用

- 从结果开始撰写 Methods / Results / Discussion
- 投稿前逐项自查
- 撰写审稿意见回复（response letter）

## IMRaD 各节要点

| 章节 | 必写内容 | 常见问题 |
|---|---|---|
| Introduction | 已知（漏斗式收窄）→ 未知（gap）→ 本研究目的 | 背景过长、没点明 gap |
| Methods | 设计 / 人群 / 干预 / 结局 / 统计方法 / 伦理批号 / 注册号 | 缺样本量估算依据、缺注册号 |
| Results | 基线 → 主结局 → 次要结局 → 亚组 → 不良事件 | 只报 P 值、缺 CI |
| Discussion | 主要发现 → 与既往研究比较 → 机制 → 局限 → 结论 | 过度外推、回避局限 |

## 报告规范对照（按研究类型选）

- **RCT** → CONSORT
- **观察性研究** → STROBE
- **系统综述 / meta 分析** → PRISMA
- **诊断准确性** → STARD

## 投稿前自查清单

1. 摘要与正文的数字**是否完全一致**（最高频硬伤，逐个数核对）
2. 所有 P 值是否附效应量与 95% CI
3. 样本量估算方法与依据是否写明
4. 伦理批号、知情同意、临床试验注册号是否齐全
5. 图表是否都在正文中被引用，且编号连续
6. 参考文献是否可能编造（交给 `citation-verify` 技能核验）
7. 利益冲突声明、数据可得性声明

## 输出

逐条给出：检查项 → 现状 → 是否通过 → 修改建议。

**发现数字矛盾必须明确列出**，不要含糊带过 —— 这类问题在审稿阶段被发现代价很高。
