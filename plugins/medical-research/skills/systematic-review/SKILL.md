# 系统综述与 Meta 分析

## 何时使用

- 启动一个系统综述 / meta 分析项目
- 设计检索策略、做题录去重
- 评估偏倚风险（RoB 2 / ROBINS-I / Newcastle-Ottawa）
- 撰写 PRISMA 流程图与清单

## 流程（PRISMA 2020）

1. **注册**：先提醒用户在 PROSPERO 注册，拿到注册号再开始
2. **检索策略**：至少两个数据库（PubMed + Embase 或 Web of Science），完整检索式与**检索日期**都要留档
3. **去重与筛选**：题录去重 → 标题摘要筛 → 全文筛，每一步记录排除数与原因
4. **数据提取**：预先设计提取表（研究特征 / 人群 / 干预 / 结局 / 偏倚）
5. **偏倚风险**：按研究类型选工具，**两人独立评估**
6. **合成**：异质性 I² > 50% 时慎用固定效应模型；做敏感性分析与发表偏倚检验（漏斗图、Egger 检验）
7. **报告**：PRISMA 清单 + 流程图 + 检索式附录

## 硬性要求

- **双人独立**筛选与提取，分歧的解决方式要记录
- 检索式必须可复现（数据库、日期、限定条件齐全）
- 异质性来源必须讨论，不能只报一个合并结果
- 纳入研究 <10 项时，发表偏倚检验可靠性低，需明确注明

## 输出

1. PRISMA 各阶段数字（识别 / 筛选 / 纳入 / 排除原因）
2. 纳入研究的特征表
3. 偏倚风险汇总
4. 合并效应量（含 95% CI、I²、模型选择理由）
