# 审稿意见回复

## 何时使用

- 收到 major / minor revision
- 需要撰写 point-by-point response letter
- 部分审稿意见不合理，需要既坚持立场又不激怒对方

## 回复信结构

```
Dear Editor and Reviewers,

We thank the reviewers for the constructive comments. We have revised the
manuscript accordingly; changes are highlighted in the revised version.

Reviewer #1

Comment 1.1: <原文照抄审稿意见>
Response:   <逐点回复>
Changes:    <修改位置，如 Page 5, Lines 120–135>
```

## 逐条处理流程

1. **先给意见分类**，不同类型用不同策略：
   - 可直接采纳 → 改了并说明
   - 需补充数据 / 实验 → 说明做了，或说明为什么做不到
   - 理解偏差 → 礼貌澄清原文意思（可能是表述不清，也要改）
   - 不合理 → 用证据反驳，同时给对方台阶
2. **每一条都必须回应**，不允许跳过或合并同类项 —— 选择性回复是审稿人最反感的
3. **标注修改位置**（页码 + 行号），方便核对
4. 修改稿中用高亮标出改动

## 措辞原则

- 先致谢再回应，但**不要过度谄媚**（"We are deeply honored by the reviewer's profound insight" 这类反而减分）
- 反驳聚焦证据与逻辑，不评价审稿人本身
- 确实做不到的修改：说明客观限制（样本量已固定、伦理不允许回溯），并承诺在"局限性"里讨论
- **不要承诺无法兑现的事**（改稿时说要做新实验，实际并不做）

## 输出

1. 完整回应信：意见 → 回应 → 修改位置
2. 修改内容清单（供自己对照改稿）
3. 若不同审稿人意见互相冲突，明确指出并说明取舍理由
