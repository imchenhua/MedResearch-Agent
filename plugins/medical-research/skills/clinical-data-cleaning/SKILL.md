# 临床数据清洗

## 何时使用

- 刚拿到原始临床数据（CSV / Excel），进入分析前的整理
- 需要生成 Table 1 基线特征表
- 数据里有明显脏值（年龄 999、性别写成「男 / 男性 / M / male」）

## 清洗流程（按序执行）

1. **先备份原始文件**，所有处理结果输出到新文件，绝不覆盖原文件
2. **概览**：行数、列名、每列缺失率、推断类型
3. **变量归类**：连续变量 / 分类变量 / 时间变量，分别制定处理方式
4. **缺失值**：报告每列缺失率；缺失超过 20% 的变量**必须提醒用户**，不要擅自插补
5. **离群值**：临床常识 + IQR 双标准识别，**标出但不自动删**
6. **逻辑校验**：年龄 <0 或 >120、出院早于入院、分组与干预冲突

## 关键原则

- **不允许静默改数据** —— 每一步都要报告改动了多少行
- 缺失值策略（删除 / 插补 / 保留）必须由用户决定，不能默认
- 分类变量合并（「男」和「male」）前，先输出映射表让用户确认

## 输出

1. **清洗日志**：每步做了什么、影响行数
2. **清洗后文件**（原文件保持不动）
3. **变量清单**：名称 | 类型 | 缺失率 | 取值范围 | 备注
4. 若生成基线表，用标准三线表：连续变量给 `mean ± SD` 或 `median (IQR)`，分类变量给 `n (%)`，并注明检验方法
